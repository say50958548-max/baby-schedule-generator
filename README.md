# 👶 Childcare Vaccine Notifier & Calendar Generator

> **"아이 예방접종 날짜, 매번 엑셀이나 수첩 찾아보기 귀찮아서 직접 만든 자동화 도구"**

대한민국 표준 어린이 예방접종 지침을 바탕으로 아이의 생년월일을 입력하면 **구글 캘린더 / 캘린더 앱에 즉시 등록 가능한 .ics 일정 파일**을 자동 생성합니다.

---

## 🚀 Key Features

- 📅 **생년월일 기반 자동 일정 계산**: B형간염, DTaP, MMR 등 필수 접종 주기 세팅
- 🗓️ **iCalendar 표준 지원**: iOS, Android, Google Calendar, Outlook 완벽 연동
- 🔔 **맞춤 알림 설정 기능**: 접종 7일 전/1일 전 푸시 알림 디폴트 탑재

---

## 🛠️ Quick Start

1. **Clone Repository**
   `git clone [github.com/say50958548-max/childcare-vaccine-notifier](https://github.com/say50958548-max/childcare-vaccine-notifier)`

2. **Directory Move**
   `cd childcare-vaccine-notifier`

3. **Run Script**
   `python main.py`

---

## 💻 Tech Stack

- **Language:** Python 3.9+
- **Library:** `datetime` (Standard Library)
- **Format:** iCalendar (.ics)
